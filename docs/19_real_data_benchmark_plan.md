# Real Data Benchmark Plan

## Purpose

This benchmark replaces the toy synthetic labels and toy spectral lines with external data.

The CSI amplitudes are still simulated, but they are generated from:

1. HITRAN line tables in the 60 to 400 GHz band.
2. Real pollutant concentration records from the UCI Beijing Multi Site Air Quality dataset.
3. A simple published style Rayleigh trend for PM.

## Targets

The benchmark estimates six variables:

1. CO.
2. O3.
3. SO2.
4. NO2.
5. PM2.5.
6. PM10.

All target labels are taken from the UCI dataset in micrograms per cubic meter.

## Feature Sets

| Feature set | Meaning |
| --- | --- |
| `path_normalized` | CSI attenuation divided by slant path factor |
| `path_normalized_relative` | Mean removed version of path normalized attenuation |
| `path_normalized_context` | Path normalized spectra plus elevation, SNR, and path factor |
| `hitran_templates` | Physics informed least squares with HITRAN templates |

## Models

1. Linear regression.
2. Ridge.
3. PLS.
4. KNN.
5. Random Forest.
6. Extra Trees.
7. HITRAN template least squares.

## Main Limitation

The labels and line data are real, but the CSI is generated by a forward model. The paper must state this clearly.
