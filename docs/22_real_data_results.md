# Real Data Results

## What Was Run

Two external data driven experiments were run:

```powershell
python scripts/run_real_data_benchmark.py --samples 20000
python scripts/run_real_ridge_sweep.py --samples 20000
```

The benchmark uses:

1. HITRAN line parameters for CO, O3, SO2, NO2, H2O, and O2.
2. Real pollutant concentration records from the UCI Beijing Multi Site Air Quality dataset.
3. A forward model that maps real concentration records to simulated CSI amplitudes.
4. A held out test split.

## Best Broad Benchmark Result

| Feature set | Model | Mean normalized RMSE | Mean R2 | Max target normalized RMSE |
| --- | --- | ---: | ---: | ---: |
| `template_projection` | `ridge_10` | 0.07793 | 0.94523 | 0.09460 |

This improves over the previous best path normalized spectrum result:

| Feature set | Model | Mean normalized RMSE | Mean R2 |
| --- | --- | ---: | ---: |
| `path_normalized` | `ridge_10` | 0.07966 | 0.94280 |

## Best Focused Ridge Sweep Result

| Feature set | Alpha | Mean normalized RMSE | Mean R2 | Max normalized RMSE |
| --- | ---: | ---: | ---: | ---: |
| `template_projection` | 17.78 | 0.07793 | 0.94523 | 0.09460 |

The optimum is very flat. Alpha values from 1 to 31.6 give almost identical results. This suggests the result is stable and not a fragile hyperparameter artifact.

## Interpretation

The best result comes from projecting CSI spectra onto external templates before supervised regression. This is physically sensible because the projection compresses spectra into components aligned with HITRAN gas signatures and PM trends.

The result is more defensible than the toy benchmark because:

1. The target distributions are real measured pollution records.
2. The gas line positions and relative strengths come from HITRAN.
3. The estimator is evaluated on held out records.
4. The toy spectral lines are not used.

## What Is Still Simulated

The CSI amplitudes are still generated by a forward model. This must be stated clearly in the paper.

The current forward model still uses simplified scaling:

1. HITRAN lines are converted to normalized templates rather than a fully calibrated absorption coefficient.
2. PM uses simple Rayleigh type smooth trends.
3. Only the main isotopologue is used.
4. H2O and O2 are treated as nuisance background templates.

## What Should Be Improved Next

1. Replace normalized HITRAN templates with HAPI absorption coefficients.
2. Implement a more rigorous PM scattering coefficient.
3. Add stratified pressure and temperature integration.
4. Run sensitivity sweeps for SNR, bandwidth, and elevation using the external data pipeline.
5. Add CRB or BCRB after the forward model is physically calibrated.

## Paper Use

These external data driven results can be used in the IEEE draft if the paper states that CSI is simulated from external datasets and published style physical models.
