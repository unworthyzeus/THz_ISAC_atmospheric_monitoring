# Data Provenance and Synthetic Evidence Audit

## Record Status

This is the canonical detailed record of where the study data came from and which evidence is measured, measurement derived, modeled, or synthetic as of 2026 07 15.

It supplements the consolidated experiment record in `docs/34_multi_method_information_floor_study.md` and the evidence boundary in `paper/main.tex`. Older planning notes remain in the repository as historical records but do not define the current data status.

## Executive Conclusion

Yes, a substantial part of the study is synthetic.

The main atmospheric experiment is best described as a **semi synthetic negative feasibility study**:

1. Pollutant concentrations and meteorological variables come from real Beijing ground monitoring records.
2. Molecular line parameters come from the real external HITRAN spectroscopic database.
3. CO and NO2 column comparisons use real ESA Climate Change Initiative satellite retrieval products.
4. The atmospheric vertical profiles, particulate matter response, non terrestrial link, receiver uncertainty, and every atmospheric THz attenuation observation are modeled or simulated.
5. No measured atmospheric sub THz channel state information is paired with the pollutant labels.
6. The `0.074855260` result that meets the `0.08` threshold is a real ground sensor single channel repair task with an artificially hidden channel. It is not THz inversion.
7. The only real measured THz spectra used in a completed score are a small aqueous protein laboratory control from Mendeley Data. They are not atmospheric measurements.

The defensible scientific conclusion is therefore conditional and negative: under the declared simulated link and noise model, the atmospheric THz observations contain too little information for the requested six pollutant inversion.

## Evidence Terminology

| Term | Meaning in this repository |
| --- | --- |
| Real measured data | Values recorded by an external physical sensor or analyzer, such as UCI ground pollution measurements or the Mendeley laboratory THz spectra |
| Measurement derived retrieval | A quantity inferred from satellite radiances by an operational retrieval system, such as ESA CCI CO or NO2 columns; it is observational evidence but not direct truth |
| Real reference parameters | External scientific parameters such as HITRAN line positions, strengths, and broadening coefficients; these are not channel observations |
| Semi synthetic experiment | Real labels or reference parameters are passed through a generated forward model to create observations |
| Fully synthetic experiment | Both labels and observations are generated by project code |
| Derived artifact | A prediction, metric, figure, manifest, bound, or summary calculated from measured or simulated inputs |
| Artificial masking | A real observed value is hidden to construct a repair or reconstruction benchmark; the value is real but the failure event is imposed by the experiment |

The word `real` must not be used without identifying what is real. Real labels do not make simulated CSI measured CSI, and a real satellite retrieval does not make the modeled THz response measured.

## Main Atmospheric THz Data Lineage

The principal atmospheric estimator follows this lineage:

```text
Real UCI Beijing concentrations and weather
                    plus
Real HITRAN spectroscopic parameters
                    |
                    v
Assumed layered atmosphere and vertical profiles
                    |
                    v
Calculated gas absorption and exploratory PM extinction
                    |
                    v
Modeled 550 km LEO link and conceptual frequency probes
                    |
                    v
Simulated attenuation plus simulated receiver error
                    |
                    v
Ridge, WLS, LMMSE, Fisher information, and CRB outputs
```

The targets are real. The atmospheric receiver observation presented to the inverse estimator is not real.

### Real Inputs to the Main Branch

1. Six UCI Beijing pollutant columns: CO, O3, SO2, NO2, PM2.5, and PM10.
2. UCI temperature, pressure, dew point, rain, wind speed, station identity, and timestamp.
3. HITRAN fields actually consumed by the physical forward model: line position, line intensity, air broadening, lower state energy, temperature exponent, and air pressure shift. Einstein A and self broadening are retained in the processed table for provenance, but the current Voigt calculation does not consume them; self broadening is omitted.

### Generated or Assumed Inputs to the Main Branch

1. Twenty four atmospheric layers from the surface to 12 km.
2. A fixed atmosphere derived from dataset medians rather than a measured profile for each observation.
3. An exponential 1.5 km scale height for the target gases.
4. A 2 km H2O scale height and dry air O2 fraction.
5. An exploratory 1 km PM mass scale height.
6. Fine and coarse PM particle diameters, densities, complex refractive indices, spherical shape, and Rayleigh extinction.
7. Plane parallel slant path scaling.
8. A 550 km satellite, 23 dBm total transmit power, 0.50 m transmit aperture, 0.30 m receive aperture, one MHz per tone, six dB receiver noise figure, and five dB implementation loss.
9. A conceptual 256 point grid from 60 to 400 GHz. These are possible multiband sensing points, not one contiguous 340 GHz waveform.
10. Pilot averaging with 30 pilots in the reference case.
11. Independent diagonal Gaussian observation errors.
12. An assumed independent residual standard deviation of `0.63` dB per tone, borrowed as a scenario value from adjacent satellite rain sensing literature and not calibrated for this link.
13. Every random receiver noise realization.

The observation contains attenuation magnitude only. It does not contain measured complex CSI, phase, Doppler, multipath, beam tracking, oscillator error, channel sounder records, or measured calibration drift.

Throughout this study, `unbounded power allocation` means that total transmit power remains fixed while no per tone allocation cap is imposed. It does not mean unlimited total transmit power. The optimizer may concentrate almost all of the fixed budget on one effective tone.

### Benchmark Population and Split

The physical and principal ground benchmark branches apply the following contract:

1. Start from 383,585 complete UCI Beijing station hour rows.
2. Exclude 17,642 rows where PM10 is below PM2.5.
3. Retain 365,943 physically ordered rows.
4. Sort by timestamp and station.
5. Select 20,000 deterministic evenly spaced rows.
6. Use 12,000 training rows, 4,000 validation rows, and 4,000 chronological test rows.
7. Calculate each normalized RMSE denominator as the training period Q95 minus Q05 span for that target.
8. Use validation to choose declared model settings.

The test period was reported before the latest follow up searches. Later results are therefore diagnostic reuse of a known test period, not pristine external confirmation.

## HITRAN Source and Processing

### Official Source

HITRAN publication page: <https://hitran.org/docs/hitran-papers/>

HITRAN2024 paper DOI: <https://doi.org/10.1016/j.jqsrt.2026.109807>

The project retrieved the current HITRAN line database through HAPI in July 2026. HITRAN is a curated collection of molecular spectroscopic parameters. It is real external scientific data, but it is not a set of measured NTN channel samples.

### Local Extraction

Frequency interval: 60 to 400 GHz, equivalent to approximately 2.001 to 13.343 inverse centimetres.

Only the main isotopologue for each selected molecule is used.

| Molecule | Role | Line count |
| --- | --- | ---: |
| CO | Target | 15 |
| O3 | Target | 1,301 |
| SO2 | Target | 6,406 |
| NO2 | Target | 1,536 |
| H2O | Background | 37 |
| O2 | Background | 45 |
| Total |  | 9,340 |

Processed table:

```text
data/processed/hitran/hitran_60_400GHz_lines.csv
```

The processed table retains line position, line intensity, Einstein A, air broadening, self broadening, lower state energy, the air temperature exponent, and air pressure shift. The reported physical forward model uses line position, line intensity, air broadening, lower state energy, the temperature exponent, and pressure shift. It does not use Einstein A or self broadening, and its current broadening treatment therefore omits self broadening.

Direct comparison with HAPI at the declared reference state gives extremely small numerical differences. This validates the project Voigt arithmetic against HAPI using the same underlying line records. It does not validate the assumed atmospheric profiles or modeled link against an independent physical measurement.

### Version Pinning Limitation

The processed SHA256 fixes the exact line table used in the reported study. The acquisition code does not store an immutable remote HITRAN response identifier, explicit server revision, or upstream response hash. A future HAPI fetch can therefore differ even if the query is unchanged. A submission archive should preserve the processed table when licensing permits or record a stronger immutable database release reference.

## ESA CCI Satellite Column Retrievals

### CO Product

Official CEDA record: <https://catalogue.ceda.ac.uk/uuid/6242532d87d442a3acf0171d35c02e56/>

Official DOI: <https://doi.org/10.5285/6242532d87d442a3acf0171d35c02e56>

The product is a monthly one degree Level 3 total CO column record that merges cloud screened IASI observations from Metop A, B, and C with MOPITT observations from Terra. It includes daytime and nighttime columns, uncertainty, surface altitude, and data source flags. The current official citation names Maya George and Cathy Clerbaux.

### NO2 Product

Official product page: <https://www.temis.nl/airpollution/no2col/cci-no2-omi.php>

Official DOI: <https://doi.org/10.21944/cci-no2-omi-l3>

The product contains OMI monthly Level 3 tropospheric NO2 vertical columns, uncertainty, temporal variability, counts, cloud information, and quality fields. The official citation names Isidora Anglou, I. A. Glissenaar, K. F. Boersma, and H. Eskes.

### Extract Used by the Study

1. Ten monthly CO files and ten monthly NO2 files were acquired.
2. The period is 2013 03 through 2013 12.
3. Each product is sampled independently at the grid centre nearest the declared Beijing point of 39.9 degrees north and 116.4 degrees east.
4. Both products select the 39.5 degrees north, 116.5 degrees east one degree grid cell.
5. The processed table contains ten paired monthly rows.
6. All 20 official objects passed the declared NetCDF coordinate and variable checks.
7. CO flags indicate combined IASI and MOPITT use in every retained month.
8. NO2 Level 3 quality flags equal one in every retained month.
9. Reported retrieval uncertainty and supporting quality fields are retained rather than replaced.

Processed extract:

```text
data/processed/columns/beijing_column_series_2013.csv
```

Acquisition manifest:

```text
data/processed/columns/beijing_column_series_2013_manifest.json
```

The raw 20 file acquisition totals 194,098,326 bytes. Each raw file has an individual SHA256 in the acquisition manifest.

### Retrieval and Model Boundary

The ESA values are measurement derived retrievals, not direct atmospheric truth. They depend on satellite instrument sensitivity, retrieval algorithms, priors, cloud screening, and averaging. Only ten coarse monthly samples are used.

The column feasibility study does not measure THz attenuation. It distributes each retrieved column through an assumed vertical profile, computes modeled absorption, and evaluates a simulated link and analytical bound. CO is a total column but is forced into the model supported 0 to 20 km domain with an assumed 8 km scale height. NO2 uses a 1.5 km tropospheric scale height. These assumptions create profile error whose sign is not known.

## Real Ground Sensor Alternatives

### Strictly Causal Forecast

The `0.095484566` causal v2 result uses only real UCI Beijing ground measurements. Its information set contains calendar, station identity, current weather, and pollutant measurements at least one hour before the query. Current and future target labels are forbidden and mutation tests confirm that they do not affect features.

This is a ground sensor forecasting task requiring functioning historical monitors. It contains no THz observation.

### All Six Channel Station Reconstruction

The `0.088889959` result artificially hides all six current pollutant values at the query station. It permits current measurements from up to 11 other stations, current weather, and exact historical measurements. Sentinel tests verify that changing the six hidden query values does not change the features.

The values used from donor stations are real. The complete station failure is imposed by masking. The result requires a synchronized ground network and is not remote THz sensing.

### Single Channel Repair

The `0.074855260` result artificially hides only target channel `j`. It permits the other five current pollutant channels at the same query station, current donor station measurements, current weather, and historical values. A target specific sentinel test verifies that the hidden current target does not enter its own repair design.

This is the only real time method in the study that reaches `0.08`. Its claim is narrow: one failed ground sensor channel can be repaired when the other five current colocated channels and the station network remain available.

### Retrospective Repair

The retrospective results use real Beijing values but allow observations after the missing query time. The strongest scores are approximately `0.066` to `0.071`. They show that the dataset supports accurate offline smoothing when future truth is available. They are not causal, online, or THz results.

## UCI Italian Field Sensor Control

Official page: <https://archive.ics.uci.edu/dataset/360/air+quality>

DOI: <https://doi.org/10.24432/C59K5F>

The official UCI record contains 9,358 hourly responses from five metal oxide chemical sensors and colocated certified analyzer concentrations. The device operated at road level in a polluted area of an unnamed Italian city from March 2004 through February 2005. UCI does not identify the city, so the data must not be attributed to Milan or another location without an additional primary source.

Missing values use the marker `-200`. After excluding that marker and requiring four reference targets, five sensor channels, temperature, relative humidity, and absolute humidity, 6,941 complete timestamped rows remain. The chronological split contains 4,164 training, 1,388 validation, and 1,389 test rows. Reference target columns are excluded from the features.

The best four target macro normalized RMSE is `0.146500`. Benzene alone reaches `0.008916`, while CO, NOx, and NO2 remain substantially worse. The benzene score cannot be reported as a four target success.

This is a real field sensor calibration task with no synthetic sensing signal. It differs from the Beijing and THz tasks in city, time, units, analytes, sensor type, and metric population.

### Reproducibility Gap

The local raw archive and its SHA256 are present, and the completed scores are documented in `docs/34_multi_method_information_floor_study.md`. The repository does not yet contain a dedicated committed downloader, analysis script, manifest, prediction table, or metric table for this branch. It is therefore less reproducible than the primary Beijing, column, and Mendeley branches.

## WHO Values Are Not Labels

The WHO 2021 values are health guideline concentration scales. They are not measurements, model targets, legal limits, or matched averaging period truth for the simulated pilot burst. Ratios between a one burst analytical floor and an 8 hour or 24 hour guideline are magnitude comparisons only.

## Legacy Synthetic and Semi Synthetic Pipelines

### Fully Synthetic Toy Pipeline

The original toy generator in `src/thz_isac/synthetic_data.py` samples gas and PM labels uniformly, samples elevation and SNR, uses invented spectral markers, and generates noisy spectra. Files under `data/synthetic/` belong to this engineering pipeline. They verify data flow and estimator behavior but do not contribute scientific evidence to the current paper.

### Superseded External CSI Benchmark

The older external data generator in `src/thz_isac/external_forward_model.py` uses real UCI labels and HITRAN derived template shapes, but it:

1. Sets each target signature scale from the full dataset target Q95.
2. Assigns configured peak losses instead of calibrated physical absorption.
3. Samples elevation and SNR.
4. Adds synthetic noise.
5. Uses the same template design in the generator and inverse projection.
6. Uses a random development split with timestamp overlap.
7. Selects configurations using the reported test results.

The resulting `0.07793` normalized RMSE and `0.94523` mean R2 are engineering self consistency results. The directory name `data/processed/real_data_csi/` must not be interpreted as measured CSI. The labels are real; the spectra are simulated.

## Bias, Leakage, and Interpretation Risks

### Complete Case Selection

Removing 8.837% of the expected UCI station hours may bias time periods, stations, or pollution regimes. The current processed table cannot identify the missingness mechanism because the incomplete rows were removed upstream.

### PM Eligibility Uses Current Targets

The principal 20,000 row branches require PM10 to be at least PM2.5. In PM channel repair, this eligibility decision uses current target values before one of them is hidden. The hidden value does not enter the feature matrix, but target dependent population selection can make the PM repair population easier or different from operational failures. This must be treated as selection bias rather than feature leakage.

### Full Period Reference State

The physical study uses some full period atmospheric medians and the full period median PM fine fraction. These are declared transductive reference assumptions. They prevent describing the entire pipeline as a strictly leakage free inductive evaluation.

### Known Test Period

The same chronological test period was reported before the latest advanced THz, causal, spatial, and repair searches. Each new script selects configurations on validation, but the broader research process already knows the test regime. The new results are diagnostic rather than pristine external confirmation.

### Oracle Physical Controls

The physical benchmark includes an explicitly labeled oracle gas WLS control that subtracts the true test PM contribution. This is a diagnostic upper control and not a usable estimator. It is not a headline result.

### Real Target Correlations

Models using multiple pollutants can exploit real covariance between targets. This is useful for sensor repair but cannot be treated as proof that each species is spectrally identifiable.

### Satellite Retrieval Dependence

ESA products are retrievals with prior, instrument, cloud, vertical sensitivity, and aggregation dependence. The ten monthly values do not define an independent truth distribution.

### Small Measured THz Control

The Mendeley score has only six or seven levels per protein. Leave one level out evaluation and full sample normalization are appropriate only as a small positive control, not as a population performance estimate.
