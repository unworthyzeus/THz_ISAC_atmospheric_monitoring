# THz ISAC Atmospheric Monitoring

Research workspace for:

**Estimation Limits of Atmospheric Monitoring with Integrated Sensing and Communication in Sub THz Non Terrestrial Networks**

The core research question is whether a sub THz non terrestrial communication link can reuse channel state information amplitudes to estimate atmospheric pollutants.

The current workspace contains:

1. Research notes and planning documents.
2. Downloaded project references.
3. A toy synthetic pipeline used only as an engineering sanity check.
4. Initial estimators and benchmark scripts.
5. An external data driven benchmark using HITRAN line data and the UCI Beijing Multi Site Air Quality dataset.
6. An IEEE style draft paper summarizing the current external data driven result.

## Important Data Rule

The toy synthetic benchmark must not be used as the main scientific evidence.

Main results must use external data or external physical parameters:

1. HITRAN spectroscopic line data.
2. Real pollutant concentration datasets.
3. Standard atmosphere models.
4. Published propagation and scattering models.

Synthetic CSI is acceptable only when generated from those external sources and clearly described as simulation based on real data.

## External Data Pipeline

Download and prepare the external data:

```powershell
python scripts/download_external_data.py
```

This script downloads:

1. HITRAN line parameters through HAPI for CO, O3, SO2, NO2, H2O, and O2 in the 60 to 400 GHz band.
2. The UCI Beijing Multi Site Air Quality dataset, DOI `10.24432/C5RK5G`.

Run the current external data driven benchmark:

```powershell
python scripts/run_real_data_benchmark.py --samples 20000
python scripts/run_real_ridge_sweep.py --samples 20000
```

Current best held out result:

| Feature set | Model | Mean normalized RMSE | Mean R2 | Max target normalized RMSE |
| --- | --- | ---: | ---: | ---: |
| `template_projection` | `ridge_alpha_17.8` | 0.07793 | 0.94523 | 0.09460 |

The CSI amplitudes are still simulated from external data and a simplified forward model. This result should be described as simulation based evidence, not field validation.
